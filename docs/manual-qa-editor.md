# BeatMarks エディタ 手動QAチェックリスト(③b成果物)

> Electron はこの環境で実行不可のため、③c(CI/E2E)で実施する項目。各行 [ ] を実機で確認。

## 起動/解析フロー
- [ ] ファイルドロップ→(複数トラックなら)入力設定画面→解析中画面→エディタの順に遷移する
- [ ] 解析開始直後、最初の進捗イベントが届くまでは「抽出中」表示になる(進捗バーがいきなり
      ステージ名を出さない)
- [ ] 入力設定でモノラルのみ選択時は stereo-split(L/R個別解析)チェックボックスが非表示になる。
      ステレオを含む選択に変えると再び表示される

## トランスポート(T4)
- [ ] Space で再生/停止が切り替わる(押すたびに反転、連打で暴走しない)
- [ ] ループ ON で loop A-B を巡回、シーク時に発火済みクリック音が止まる
- [ ] メトロノーム ON でビートにクリックが乗る(小節頭は高音)
- [ ] タップテンポで BPM が上書きされグリッドが再生成される(4タップ未満では確定しない、
      タップ間隔が空くと2秒でリセットされる)
- [ ] タイムコードが指定 fps で表示される
- [ ] 再生終了(バッファ終端への自然到達)で自動的に停止表示に戻る。シーク・一時停止操作の
      直後には誤って「終了扱い」にならない

## グリッド補正バー(T8)
- [ ] BPM をクリック→直接入力→Enter で確定、30..300 外は shake で拒否
- [ ] −10/−1/+1/+10ms でオフセットが増減、表示が +NNms
- [ ] 拍子 4/4・3/4・6/8 切替でグリッドが変わる
- [ ] 1拍目 ←/→ で小節頭がずれる、アンカー設定/解除が効く
- [ ] キー表示(名前・Camelot・信頼度)が出る、Undo/Redo ボタンが状態連動

## 波形/オーバービュー/セクション帯(T5/T6)
- [ ] ホイールでカーソル中心ズーム、オーバービューのドラッグで表示範囲移動
- [ ] 拍/小節グリッド+小節番号、静寂ハッチ、アンカー旗、フリー区間の減光
- [ ] セクション境界ドラッグ移動/ダブルクリックでリネーム
- [ ] プレイヘッドが再生に追従(Transport の再生状態と波形上のプレイヘッドが常に一致する)

## ヒットレーン(T7)
- [ ] 低/中/高の3レーンにティック、感度スライダーはドラッグ中も見た目が即座に増減する
      (再解析なし)
- [ ] 感度スライダーはドラッグ中は Undo 履歴に積まれず、指を離す(またはフォーカスを外す)
      タイミングで確定した1件だけが Undo 履歴に積まれる(ドラッグ中の連打でUndoスタックが
      汚染されない)
- [ ] ティッククリックで選択がテーブルと同期

## マーカーテーブル(T9)
- [ ] 種別フィルタチップ、行クリックでジャンプ+選択
- [ ] 手動/セクションのリネーム、削除→削除済みトグルから復元
- [ ] ソース横断表示で全ソースのマーカーが時刻順に並ぶ
- [ ] 別ソースに切り替えても、切り替え前に選択していた行のハイライトが新しいソース側の
      たまたま同じIDを持つ行に「幻の選択」として残らない(ソース跨ぎのハイライト汚染がない)

## 書き出し(T10)
- [ ] fps/丸め/含めるマーカー/ソース選択、ターゲット複数選択
- [ ] 保存先ダイアログ→指定フォルダに全ファイル生成、成功/失敗トースト
- [ ] wav入力は元音声に cue 埋め込み、動画入力は抽出WAVに埋め込み
- [ ] 6/8 の MIDI で拍子分母が 8(無音破損しない)
- [ ] 複数ソースを選択して書き出す際、1ソースだけ解析データや設定が不正で失敗しても、
      他の正常なソースの書き出しは成功し、失敗したソースだけが結果表示にエラーとして出る
      (1件の異常で全ソースが無言で失敗しない)
- [ ] IPC呼び出し自体が失敗する(切断等)場合も、無反応のまま固まらずエラーが表示され、
      書き出しボタンが再度押せる状態に戻る

## .bmk/メニュー(T11)
- [ ] 保存/別名で保存、再オープンで mediaPath から波形再抽出
- [ ] mediaHash 不一致で「続行/中止」ダイアログ
- [ ] 最近使ったファイル(最大5)、タイトルに未保存 • 表示
- [ ] メニュー 開く/保存/取り消し/やり直しが効く
- [ ] 未保存の変更がある状態で メニュー→開く/最近使ったファイル を選ぶと確認ダイアログが出る。
      キャンセルすると現在の編集はそのまま残り、承諾すると別プロジェクトへ切り替わる

## ショートカット/統合(T12)
- [ ] M で手動マーカー、←→で拍シーク、Shift+←→で小節シーク
- [ ] `,`/`.` で選択マーカー(なければグリッドオフセット)を ±1ms(無修飾)/±10ms(Shift)nudge
- [ ] 1〜4 でレーン表示切替(1=拍グリッド、2=セクション帯、3=ヒットレーン、4=静寂)、
      ⌘Z/⇧⌘Z で取消/やり直し
- [ ] テキスト入力欄(BPM直接入力等)にフォーカス中は上記のショートカットキーが誤発火しない
- [ ] 非アクティブソースの取消(Undo)でタブが自動的にそのソースへ切替わり、トーストで
      通知される。やり直し(Redo)でも同様に切替わる
- [ ] グリッド補正バーの Undo/Redo ボタンをクリックした場合も、キーボードショートカットと
      同じくソース自動切替+トーストが起きる(操作経路によって挙動が変わらない)
- [ ] ソースタブ切替で表示(波形・マーカー・グリッド)が正しく切り替わる
- [ ] メニューの Cmd/Ctrl+Z・Cmd/Ctrl+Shift+Z とアプリ内ショートカットの両方から取消/やり直し
      操作をしても、二重に取り消し/やり直しが走らない(1回の操作につき1回だけ反映される)
